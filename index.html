SuperSender 是一款面向运维与测试人员的桌面网络工具：把 Syslog / TCP / UDP 的客户端发包与服务端监听收进同一个原生窗口，定速压测、多目标发送、报文模板、实时统计与日志落盘开箱即用。

核心能力

从发一条报文，到压满一条链路

不再在脚本、命令行与抓包工具之间来回切换。会话、报文、速率、统计与接收日志都在同一个窗口里完成。

三协议 · 六种角色

Syslog、TCP、UDP 各自提供客户端与服务端，新建会话时按「协议 + 模式」两步选定，互不干扰。

定速压测与多目标

按条数或时长自动停止，速率精确到条/秒；多目标表格批量下发，UDP 还支持全网段广播。

报文模板与变量

10 套内置模板，${date}、${uuid}、${random_hex} 等变量动态生成内容；可直接编辑、加载样本文件或按行循环发送。

TCP 分帧自由配置

原始裸流、分隔符、固定长度、长度前缀四种模式，长度头字节数、大小端与长度含义均可对齐业务协议。

实时统计与速率曲线

累计发送 / 接收、实时速率、字节速率、运行时长与接入终端数一屏可见，曲线随主题切换配色。

接收日志与检索

高吞吐批量渲染、关键字查询高亮、命中结果导出与实时落盘，最近 5000 条随时回看。

协议支持

三种协议，收发两端都能测

同一套操作习惯贯穿所有协议：左侧管理会话，右侧卡片化配置，启动即可观测。

01

Syslog

面向日志平台的标准 Syslog 收发，内置 RFC3164 封装与发送预览。

客户端 Facility / Severity / Hostname / Tag 可调，支持自定义前缀、多目标发送与发送前报文预览。
服务端 按网卡绑定监听端口，实时统计接收条数与速率，日志可查询、导出与落盘。
02

TCP

长连接收发与监听，覆盖从裸流到长度前缀的常见应用层分帧方式。

客户端 连接超时、断线重连、NoDelay 与 KeepAlive 可选，配合分帧配置精确还原业务报文。
服务端 多连接并发接收，可限制最大连接数并开启「接收回显」做双向链路自测。
03

UDP

无连接报文的快速下发与监听，适合高频小报文与广播场景。

客户端 多目标批量发送、广播开关、发送编码可选 UTF-8 / GBK，速率与停止条件同样可配。
服务端 绑定指定网卡接收，端口占用自动探测并显示占用进程，启动前即可避开冲突。
技术架构

原生桌面，全离线运行

基于 Wails v3 构建，Go 负责网络与系统能力，Vue 3 负责界面，全部资源内置，不依赖 CDN。

  • 原生窗口与托盘系统 WebView 渲染，窗口与托盘图标运行时生成；关闭确认、托盘菜单与退出时自动停止服务。
  • Go 网络引擎客户端调度、服务端监听、TCP 分帧编解码、统计采样与端口占用探测全部由 Go 处理，稳定高效。
  • 卡片化前端Vue 3 + Element Plus + Pinia，任务卡片可拖拽、缩放并保存布局，两种主题随系统偏好切换。
  • 离线可用Monaco 编辑器、图标与主题全部内置，中英双语即时切换，无网络环境同样完整工作。
