# SuperSender

[English](README.en.md) | 简体中文

[SuperSender](https://gegecoder.github.io/SuperSender/) 

> 桌面网络发包 / 压测 / 报文监听工具

SuperSender 面向运维与测试人员，将 **Syslog / TCP / UDP** 三类协议的「客户端发包」与「服务端监听」整合到同一原生桌面应用中：支持定时定速发包、多目标批量发送、报文模板与变量、实时速率统计、接收日志落盘、端口占用探测等能力，开箱即用，无需命令行。

- 作者：心歌（<eclipse8@qq.com>）
- 博客：<https://kevin.blog.csdn.net>
- 更新地址：<https://gitcode.com/qq_23994787/SuperSender/releases>

## 典型用法

1. 点击左侧「＋」新建会话，选择协议（Syslog / TCP / UDP）与模式（客户端 / 服务端）。
2. **服务端**：选择绑定网卡与监听端口，启动监听；TCP 可开启「接收回显」做链路自测。
3. **客户端**：填写目标 IP / 端口、发送编码、速率与停止条件；需要压测时开启多目标。
4. 在「报文来源」中选择模板、加载样本文件或直接编辑（Syslog 客户端会实时预览封装后的完整报文）。
5. 启动后通过「实时统计」观测速率曲线，在「接收报文」区查看 / 导出 / 落盘接收内容，右上角「日志」查看运行详情。
